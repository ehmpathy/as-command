# case=5 — unawaited logs, then the logic throws (the densest walk)

## narrative

an author's logic logs progress in a loop without await, then hits a bad record and throws. the author's caller gets the thrown error back, unchanged. in `log.json` the author finds the input entry, every progress entry in the order fired, then `output.error` with the message, then `]` — the error sits after the work that led to it, never before it, and the file is sealed.

## bdd

```
[t0] given logic that fires N log.info calls without await, then throws
[t1] when  the command is invoked
[t2] then  the caller receives the thrown error
[t3] and   log.json holds `input`, the N entries in call order, then `output.error`
[t4] and   `]` is the last write, after `output.error`
```

## boundaries crossed in one walk

- seam: logic → unawaited log calls → the chain
- limit: all N entries, none dropped, none reordered
- rejection: the thrown error reaches the caller and the log
- seam: `finally` → the final `]` on the same chain
