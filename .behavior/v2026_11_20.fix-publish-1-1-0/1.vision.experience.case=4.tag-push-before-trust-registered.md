# case=4 — a tag push before trust is registered

sharp × critipath. it already happened: run `44309703170`, tag `v1.1.0`, 2026-11-18. this demo is the incident the wish exists to cure.

## narrative

the releaser merges #10's practice upgrade, and please-release tags `v1.1.0`. they watch the actions tab: `test` goes green, then `publish` goes red about 15 seconds into its job. they open it and read one `::error::` line: `oidc: not configured for @ehmpathy/as-command (http 404)`, with the npm access url. they check npm, and 1.0.5 is still latest; no partial or wrong 1.1.0 exists. the red run was fast and loud, and it named where to go. it did not name what to enter there, and the releaser cannot open that page without npm maintainer rights.

## timeline

