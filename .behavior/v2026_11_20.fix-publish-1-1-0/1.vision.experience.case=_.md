## rerun scope — a cross-cut on every rerun row

`gh run rerun` takes the whole run or only its failed jobs. the publish job restores node_modules from the install job's cache with no fallback install (`.publish-npm.yml`), and the cache evicts 7 days after its last read (2026-11-18 → ~2026-11-25).

| outcome | verdict | feel × care |
|---|---|---|
| full rerun (`gh run rerun 44309703170`) | demoed — `case=1` [t2]; install reruns, and rebuilds the cache on a miss, so cache age never bites | happy × critipath |
| `--failed` rerun, cache still live | itemized — install is skipped, the restore hits, and the run walks its trust row | happy × alterpath |
| full rerun, a `test` job flakes | itemized — the run goes red before `verify oidc auth`, so trust stays untested; the install job restored or rebuilt the cache, and a restore renews its 7-day clock, so a `--failed` rerun within 7 days is safe and walks the trust row | sharp × alterpath |
| any rerun more than 2 days after the record was saved, with no publish yet | itemized — npm expired the record, so `verify oidc auth` returns the same 404 as an absent one; the record cannot be edited, so the maintainer deletes it and adds it fresh, then the rerun walks `case=1` | sharp × alterpath |
| `--failed` rerun, cache evicted | itemized — install is skipped, the restore misses; with trust `publish.yml` the run passes oidc, then `npm run build` goes red with no node_modules. 1.1.0 is not published. caught by `.dream/v2026_11_20.reseed.publish-installs-on-cache-miss.md` | sharp × alterpath |
