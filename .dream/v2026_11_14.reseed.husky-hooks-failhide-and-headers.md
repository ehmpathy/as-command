## .the gap, precisely

- `check.yalc.sh:5` — `yalc check 2>/dev/null` inside `$(…)`: a malfunctioned check yields empty stdout and reads as clean (failhide)
- `check.yalc.sh:6` — `✋ package.json has yalc references…` names no `ConstraintError:` class, and the branch does not `exit 2`, so the commit proceeds
- `check.commit.sh:6`, `check.yalc.sh:9` — a tool absent → `🟡 … not available, wont check …`, exit 0: the check silently does not run; the header names no class
- `check.commit.sh:4` — a rejected message exits commitlint's own code (1), not the constraint code (2)
- `check.nvm.sh:5` — the body is commented out; the hook runs no check and reports success
- `check.commit.sh`, `check.yalc.sh` — `else` branches where guard clauses would read flat
- `check.timestamps.sh:10` — an all-caps comment (`NEVER ADD AN EXEMPTION …`)
- `check.timestamps.lock.sh` (`timestamps_lock_halt "$1" "$2"`), `check.lockfile.sh` (`changed "$1"`) — positional bash args
- none of the hooks' error / blocked states has an acceptance test with a snapped stderr

## .the shape of the fix

- yalc: capture the exit status of `yalc check`; on failure print `💥 MalfunctionError:` and exit 1; on found refs print `✋ ConstraintError:` to stderr and exit 2
- absent tool: decide one policy for the practice — either `💥 MalfunctionError:` + exit 1, or a qualified, loud skip — and apply it to every hook alike
- commitlint: map a non-zero result to `✋ ConstraintError:` + exit 2
- nvm: delete the hook from the chain, or restore a check that can run in the hook shell
- lowercase the shouted comment; named args (`found=… where=…`) in the bash fns
- an acceptance suite that drives each hook against fixture staged blobs and snaps stderr

## .why it is not done in this round

the files are practice-owned and arrive byte-identical from `declapract-typescript-ehmpathy@0.50.0`; the wish is the bottleneck drop. an adopter-side edit drifts and is reverted on the next apply. fulcrum F05 records the call.
