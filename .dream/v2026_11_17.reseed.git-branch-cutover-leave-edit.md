## .the gap, precisely

- the carry halts on any tracked edit to a file absent on the new branch; its fix line says "commit or drop the edit first"
- the asks log is written by the achiever hook on every human message, so a drop is undone at the next ask
- `goal.guard` forbids any direct access to `.goals/`, so no paved command can drop the edit at all
- ⇒ a route-bound branch whose asks log was once committed can never cut over

## .the shape of the fix

- a `--leave <glob>` flag on `begin`: the matched tracked edits stay parked on the source branch, untouched, and the plan lists them as left
- default-leave any path under `.goals/` (the asks log is kept out of commits by policy)
- clamp: integration case with an edited tracked file absent on the base; plan halts without `--leave`, applies with it
