# 🌙 dream: `git.branch.rebase take` labels each side by the name it takes

- kind: reseed (ehmpathy/rhachet-roles-ehmpathy, role=mechanic, skill `git.branch.rebase take`)
- owner: rhachet-roles-ehmpathy maintainers
- caught 2026-11-20

## .the cue that fired

as-command pr #9, rebase onto origin/main, conflict on `e38ddc7 fix(deps)`. intent: config files to main's side, src files to the fix side. `take --whos ours` on the config files printed `whos: ours (your commit)` and wrote the fix commit's content; `take --whos theirs` on the src files printed `whos: theirs (main)` and wrote main's content. both landed inverted from a raw-git read, where in a rebase `ours` = the upstream and `theirs` = the commit replayed.

## .the gap, precisely

- the skill maps `ours` → the replayed commit and `theirs` → main: the reverse of git's rebase semantics, and the reverse of every git doc a caller has read
- the map is printed only after the write, so the first sign of the inversion is a settled file with the wrong content
- once settled, `take` refuses a second pass (`no files in conflict`), so the repair is a by-hand write from `git show <sha>:<path>` plus a stage
- and `rebase continue` would commit the inverted index with no check

## .the shape of the fix

- replace `--whos ours|theirs` with side names that cannot be misread: `--whos main|mine` (or `--whos upstream|replayed`); refuse `ours`/`theirs` with a ConstraintError that names the new values
- plan by default: show, per file, which commit's content each side would write, before the write
- allow a re-take of a file settled by `take` in this same stop, so a wrong pick is one call to undo
- clamp: a temp repo whose rebase conflicts on one file; `take --whos main` writes origin/main's blob, `take --whos mine` writes the replayed commit's blob; assert each by blob hash

## .why it is not done in this round

the skill belongs to rhachet-roles-ehmpathy, not this repo. the inversion on #9 was repaired by hand in the tree; it lands with the rebase once the commit switch reads allowed.
