# 🌙 dream: the publish job installs node_modules on a cache miss

- kind: reseed
- owner: ehmpathy/declapract-typescript-ehmpathy (the `.publish-npm.yml` practice)
- caught 2026-11-20

## .the cue that fired

as-command's cure is a rerun of failed publish run `44309703170`. a peer review found that `gh run rerun --failed` reruns only the publish job. that job restores node_modules from the install job's cache, and the cache evicts 7 days after its last read.

## .the gap, precisely

- `.install.yml` installs on a cache miss (`node-modules cache miss install`)
- `.publish-npm.yml` restores the same key with `actions/cache/restore` and no `fail-on-cache-miss`, and has no install step
- ⇒ a `--failed` rerun of a run older than the cache passes oidc, then `npm run build` runs with no node_modules and goes red with an error that points away from the cause

## .the shape of the fix

in the practice's `.publish-npm.yml` publish job, after the restore, add the same cache-miss steps `.install.yml` holds (setup node, setup pnpm, `pnpm install --frozen-lockfile`), gated on `steps.cache.outputs.cache-hit != 'true'`. the cheaper floor is `fail-on-cache-miss: true`, which fails loud but still blocks the rerun.

## .why it is not done in this round

the file is owned by the practice; a local edit drifts on the next `declapract upgrade`. this route sidesteps it with a full rerun, which reruns the install job.
