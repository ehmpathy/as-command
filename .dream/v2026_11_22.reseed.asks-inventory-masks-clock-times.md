## .the cue that fired
a route's done-gate commit was refused by the `check.timestamps` pre-commit hook on `.goals/asks.inventory.jsonl`: the achiever's prompt hook had stored three director messages verbatim, each with a clock time. the goal guard then refused every move on that path, an unstage included, so the clone could neither mask, drop, nor commit it.

## .the gap, precisely
- the inventory lives in a tracked route directory, and a stage of the route directory picks it up
- it stores peer text raw, so any clock time a peer types lands in a tracked file
- the ehmpathy practice hook forbids a clock time in every tracked file but `.ts`/`.sh`, with no exemption
- the goal guard blocks the driver from any repair, so the only exit is a human

## .the shape of the fix
one of, decided by the achiever's owner:
- mask clock times (`HH:MM`, `HH:MM:SS`, `T`-forms, any zone) to `[timestamp]` before the inventory write, the same mask the timestamp hook names
- or ship a `.gitignore` beside the inventory, if the inventory is session state rather than an audit record
- and in each case, a clamp: a test that writes an ask with a clock time and asserts the stored line passes the practice's timestamp pattern
